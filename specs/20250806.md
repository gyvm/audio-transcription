## 設計書：複数API対応文字起こしアプリ機能拡張

### 1. 概要

既存の文字起こしアプリに以下の機能を追加する：
- 複数API選択機能（チェックボックス形式）
- リクエスト/レスポンス表示機能（折りたたみ式）
- 非同期結果表示対応

### 2. アーキテクチャ設計

#### 2.1 API抽象化レイヤー

```typescript
// API共通インターface
interface TranscriptionAPI {
  name: string;
  id: string;
  transcribe(audioFile: File, options?: any): Promise<TranscriptionResult>;
  formatRequest(audioFile: File, options?: any): any;
}

interface TranscriptionResult {
  apiId: string;
  success: boolean;
  text?: string;
  error?: string;
  request: any;
  response: any;
  timestamp: Date;
  processingTime: number;
}

// API Registry パターンで拡張性を確保
class APIRegistry {
  private apis: Map<string, TranscriptionAPI> = new Map();
  
  register(api: TranscriptionAPI): void {
    this.apis.set(api.id, api);
  }
  
  getAll(): TranscriptionAPI[] {
    return Array.from(this.apis.values());
  }
  
  get(id: string): TranscriptionAPI | undefined {
    return this.apis.get(id);
  }
}
```

#### 2.2 個別API実装例

```typescript
// Whisper API実装
class WhisperAPI implements TranscriptionAPI {
  name = "OpenAI Whisper";
  id = "whisper";
  
  async transcribe(audioFile: File, options?: any): Promise<TranscriptionResult> {
    const startTime = Date.now();
    const request = this.formatRequest(audioFile, options);
    
    try {
      const response = await this.callWhisperAPI(request);
      return {
        apiId: this.id,
        success: true,
        text: response.text,
        request,
        response,
        timestamp: new Date(),
        processingTime: Date.now() - startTime
      };
    } catch (error) {
      return {
        apiId: this.id,
        success: false,
        error: error.message,
        request,
        response: error,
        timestamp: new Date(),
        processingTime: Date.now() - startTime
      };
    }
  }
  
  formatRequest(audioFile: File, options?: any) {
    return {
      file: audioFile.name,
      model: options?.model || "whisper-1",
      language: options?.language
    };
  }
}
```

### 5. 技術的考慮事項

**拡張性の確保:**
- Factory パターンでAPI実装を動的に追加可能
- 設定ファイルでAPIリストを管理

**状態管理:**
- 複数の非同期処理の状態を適切に管理
- React Context or Redux での状態集約

**エラーハンドリング:**
- API別のエラー表示
- リトライ機能の検討

**セキュリティ:**
- APIキーの安全な管理
- ファイルアップロードの制限
